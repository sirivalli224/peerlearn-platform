# PeerLearn – Peer-to-Peer Learning Platform

## 📌 Project Overview
PeerLearn is a web-based platform that helps students connect with peers to share knowledge, exchange learning resources, request tutoring, and provide feedback. It encourages collaborative learning and makes it easier for students to learn from one another.

## 🎯 Objectives
- Connect students based on their skills and learning interests.
- Share useful study materials and resources.
- Enable students to request and provide peer tutoring.
- Allow students to review and rate their learning experiences.
- Provide a simple and user-friendly learning environment.

## ✨ Features
- **User Authentication:** Login and signup functionality.
- **Dashboard:** Overview of the platform's learning activities.
- **Find Peers:** Discover students with different skills and interests.
- **Learning Resources:** Share and access study materials.
- **Tutoring Requests:** Request peer-to-peer learning assistance.
- **Reviews and Ratings:** Provide feedback about learning experiences.

## 🛠️ Technologies Used
- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JSON Web Tokens (JWT), bcryptjs
- **Development Tools:** Visual Studio Code, Git, GitHub
